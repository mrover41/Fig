# About project

It`s a "injector", or it also clled "hooker" on C

# How to compile this

To compile all project use this command:
```bash
make
```

To compile only loader use this:
```bash
make main
```

To compile only modules use:
```bash
make modules
```

To compile one module use:
```bash
make module_name
```

If u want compile debug version, use flag `DEBUG=1`<br>
For example:
```bash
make main DEBUG=1
```
